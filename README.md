# Innovasion

My first ever frontend development project, built using HTML and CSS.

Innovasion is an anime-inspired website created as my first practical
frontend development project. The project focuses on practicing
HTML structure, CSS styling, layouts, and visual design.

- CSS3

## Project Type

Frontend Development

- Anime-inspired visual design
- Custom CSS styling
- Image-based content sections
